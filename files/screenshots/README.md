# UI illustrations

These images illustrate the interface, not a production audit or acceptance
record. Captured account, filesystem and record fields in the development
screenshots have been replaced with synthetic examples. Benchmark screenshots
show fictional simulated scenarios, not actual incidents or customer data.

Before replacing or adding an image, inspect its full-resolution pixels and
metadata. Use demo accounts, synthetic paths, example domains and fictional
records. Do not rely on a text search, credential redaction or background blur
to remove private content from an image.
