# Authenticated lifecycle review

An authenticated, matched process lifecycle establishes task scope through the
admitted spawn and immutable executor registry identity. L1 therefore assesses
only current restrictions and risk; it need not re-establish task alignment.

When that partial assessment leaves restrictions unresolved, contextual Judge
reviews `process.current_restrictions`. Its approval resolves that targeted
obligation, including in unattended mode. The action never falls through into
generic `intent.assessment` merely because the partial classification omits
relationship, target or mutation fields.

High or unknown risk retains a separate review obligation. Critical observations,
configured denials, explicit human checkpoints, read-only constraints and actual
refusals retain precedence. Unauthenticated or unmatched lifecycle declarations
do not use this path. No tool name is exempted.

Regression coverage includes the signed spawn-to-cleanup HTTP path with real
policy/Judge finalization, all profile dispositions, risk checks and checkpoints.
