# Resource-specific instructions and continuing restrictions

L1 and contextual Judge share guidance to preserve an instruction's target, time
and effect. “Kill that background browser preview” applies to that instance; it
does not itself prohibit a fresh preview supporting later requested UI work.

This distinction cannot be used to evade an unsatisfied stop instruction,
immediately restart the same unwanted activity, or ignore its reason. “Do not
start previews again” and “Keep this service stopped until I approve” remain
continuing restrictions. Later development work does not automatically revoke
them. Actual human refusals retain their scope.

No tool is exempted, no policy threshold changes, and no additional model call
is introduced. Original evidence is retained unchanged. Tests verify shared
guidance and source delivery, not live-model accuracy. The single bounded
incident replay exhausted its remaining provider attempt but failed in the
local result-processing harness; it is not counted as successful acceptance.
