# Conditional child assignments

Alignment distinguishes mandatory work from optional operations explicitly
conditioned on the parent's restrictions. A related debrief can complete with
read-only inspection or no permitted changes when persistence is forbidden.
Listing optional memory, skill or wiki updates is not an unconditional write
instruction.

This does not exempt hooks. Required conflicting operations, unrelated tasks
and applicable prohibitions on delegation or spawning children still fail
alignment. A generic disclaimer does not cancel mandatory conflicting steps.
Alignment is not a grant for individual tools; normal action evaluation and
the parent's restrictions remain in force.

The change updates model guidance only. Boundary tests verify preservation of
source evidence, prompt instructions and model verdicts, not live-model accuracy.
Previously denied sessions are not rewritten or automatically approved.
