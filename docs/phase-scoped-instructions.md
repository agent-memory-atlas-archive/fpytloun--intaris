# Phase-scoped instructions

Extraction, L1 and Judge share guidance for phase-bounded restrictions.
An authoritative later approval to build the agreed work supersedes the earlier
planning-only request and its "no code edits this turn" restriction. Independent
limits on pushing, secret files, worktree boundaries or particular edits remain.

Elapsed time, agent assertions, ambiguous continuation and unrelated new work
do not establish a phase transition. This is not a global latest-message-wins
rule, a tool exemption, or a change to deterministic policy controls. Generated
status labels cannot override clear original instructions.

The extraction and L1 presentation versions are bumped so old extracted profiles
are not treated as current-format evidence. Existing audit decisions are not
rewritten. Tests cover source/status transport and shared prompt wiring using
scripted model outputs; they do not prove live-model interpretation accuracy.
